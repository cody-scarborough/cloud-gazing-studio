# Cloud Gazing Studio

Build a web app that is like a fun mindfulness activity where you look at clouds in the sky and then write what they look like, like that game people sometimes do as kids, but make the clouds realistic and the background beautiful with little surprises like geese, etc. And there should be a way to maybe blow wind or something to get more clouds, I dunno. Let's start with that?
